# ST-0205 전단사함수 (Bijective Function)

## 정의 (Definitinon)

> [!NOTE] ST-0205 전단사함수 (Bijective Function)
> **정의**
> 함수 $f:X\longrightarrow Y$가 전사함수이고 단사함수일 때 $f$를 **전단사함수(bijective function)** 또는 **1대1 대응(one-to-one correspondence)** 이라고 한다.
>
